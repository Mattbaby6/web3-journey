# 难点库索引

**用法**：Matt 遇到觉得难的题 → 拍照发给 AI → AI 转录成 `R<编号>.md` 并在此登记。
**复习**：每 3 天，AI 从未到期的条目里抽 1–2 题让 Matt 重做，然后更新本表。

**间隔规则**：做对 → 间隔 ×2（3→6→12→24 天）；做错 → 回到 3 天；连续 3 次做对 → `已掌握`。
