## 卡在哪（两个根本性错误）

### 错误 ①：变量名加了引号

```js
"myAdjective "   ← 有引号
"myNoun"         ← 有引号
```

**加了引号，它就不是变量了，它就是那串字母本身。**

| 写法 | 引擎的行为 |
|---|---|
| `myNoun` | 打开盒子，取出里面的 `"dog"` |
| `"myNoun"` | 把 `myNoun` 这六个字母原样输出 |

**比喻**：
> 盒子上贴着标签「myNoun」，里面装着 dog。
> 写 `myNoun` = 打开盒子取出 dog。
> 写 `"myNoun"` = 把标签撕下来复印一份——你拿到的是标签纸，不是狗。

**引号的作用：把「代码」变成「文字」。**

### 错误 ②：`+` 不自动加空格

```js
"I have a" + "myAdjective "   →  "I have amyAdjective "   ← a 和 myAdjective 粘连
myVerb + "really"             →  "ranreally"              ← ran 和 really 粘连
```

**`+` 只是把两段文字首尾相接，中间不会插入任何东西。空格必须自己写。**

```js
"ran" + "really"         // → "ranreally"     ❌
"ran" + " " + "really"   // → "ran really"    ✅
```

## 正确写法

```js
const wordBlanks = "I have a " + myAdjective + " " + myNoun + " and it " + myVerb + " really " + myAdverb + ".";
```

**产出**：`I have a big dog and it ran really quickly.`（四个词全部命中）

**空格来源拆解**：

```
"I have a "       →  I have a␣      ← 结尾空格
+ myAdjective     →  big
+ " "             →  ␣              ← 单独补空格
+ myNoun          →  dog
+ " and it "      →  ␣and it␣
+ myVerb          →  ran
+ " really "      →  ␣really␣
+ myAdverb        →  quickly
+ "."             →  .
```

## 为什么这条最重要（★★★☆）

**这是「变量 vs 字符串」的分水岭。**

- 没跨过去 → 后面所有涉及变量的题都会反复错，且**错误很难自查**（因为代码不报错，只是输出悄悄错了）
- 跨过去了 → 变量、字符串、拼接、模板字符串（P2 的 TypeScript 会升级成 `` ` `` 模板字面量）全部顺畅

**两个必须固化的规则**：

```
① 变量名不加引号
② + 不自动加空格，" " 要自己写
```

**自查方法**：把结果用 `JSON.stringify()` 打印出来，**所有看不见的空格都会现形**。
