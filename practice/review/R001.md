## 原题

> `remainder（%）` 运算符返回两个数相除得到的余数。
> 使用 `remainder（%）` 运算符，计算 **11 除以 3** 的余数，并把余数赋值给变量 `remainder`。

---

## 我第一次的答案（❌ 未通过）

```js
const remainder ;
remainder = 11%3;
```

**测试结果**：①通过 ｜ **②失败 ——「remainder 的值应该等于 2」** ｜ ③通过

---

## 卡在哪

**`const` 声明必须同时初始化。**

```js
const remainder ;     // ← 语法错误：Missing initializer in const declaration
remainder = 11%3;     // ← 这行根本不会被执行
```

`11 % 3` 的算术**本身是对的**（= 2）。**错的是声明方式，不是运算。**

正确写法二选一：

```js
const remainder = 11 % 3;   // 声明即赋值（推荐）
```

```js
let remainder;              // 先声明
remainder = 11 % 3;         // 再赋值
```

**为什么 `const` 特殊**：`const` 声明的变量**不能被重新赋值**。
所以语言设计上它必须"出生就带着值"——不允许先声明、后赋值。
