## 原题

用转义字符把下面三行文本赋值给变量 `myStr`：

```
FirstLine
	\SecondLine
ThirdLine
```

> 注意：`SecondLine` 前面的空白是**制表符**，不是空格。
> 题目原文提示：「**请注意，反斜线本身必须被逃脱才能显示为反斜线。**」

---

## 我第一次的答案（❌ 未通过）

```js
const myStr = "FirstLine\n\t\SecondLine\nThirdLine";
```

**测试**：①✅ ②✅ ③✅ ④✅ **⑤❌** ⑥✅ **⑦❌**

失败信息：「`SecondLine` 前面应该是反斜杠 `\`」

---

## 卡在哪

**`\S` 不是合法的转义序列。**

在 JavaScript 字符串里，反斜杠是**引导符**——它声明"后面那个字符有特殊含义"：

| 写法 | 引擎的行为 | 结果 |
|---|---|---|
| `\n` | n 有特殊含义 | 换行 |
| `\t` | t 有特殊含义 | 制表符 |
| **`\S`** | **S 没有特殊含义** | **丢弃反斜杠，只留 `S`** |

所以 `"\SecondLine"` 实际等于 `"SecondLine"` —— **反斜杠凭空消失**。

---

## 正确写法

想得到**字面的反斜杠**，必须用反斜杠转义它自己：

```js
const myStr = "FirstLine\n\t\\SecondLine\nThirdLine";
```

```
  \        \
  ↑        ↑
  │        └── 被转义的字符（反斜杠本身）
  └─────────── 引导符
             ↓
        结果：一个 \
```

## 深层原因

### ① 这是「静默失败」

| | R001（`const`） | R002（`\S`） |
|---|---|---|
| 引擎反应 | **报错** | **不报错** |
| 有无信号 | 有（报错信息） | **无** |
| 谁会发现 | 任何人 | **只有测试** |

**`\S` 这类错误最阴险**——环境不会提示，它悄悄丢掉字符。
唯一的防线是**记住规则本身**，不能靠试错。
